CampusFix

Campus Complaint Reporting and Management System

CampusFix is a simple web-based platform that allows students to report campus problems and track their complaints digitally.

🚀 Features

- Student Login
- Report Campus Problems
- Complaint Photo Upload
- View Submitted Complaints
- Complaint Status Tracking
- Student Profile
- Admin Login
- Admin Dashboard
- Search and Filter Complaints
- Update Complaint Status

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

🎯 Purpose

CampusFix aims to make campus problem reporting easier, faster, and more organized by connecting students and campus administration through a simple digital system.

📂 Project Structure

- "index.html" — Student Login
- "dashboard.html" — Student Dashboard
- "report.html" — Complaint Reporting
- "admin-login.html" — Admin Login
- "admin.html" — Admin Dashboard
- "style.css" — Website Styling
- "script.js" — JavaScript Logic

🔮 Future Scope

- Backend database integration
- Real-time notifications
- User authentication
- Admin and student accounts
- Complaint analytics
- Cloud image storage
